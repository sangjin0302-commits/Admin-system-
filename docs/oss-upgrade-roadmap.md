# OSS Upgrade Roadmap (Admin Office MVP)

## 목표
- 현재 운영 중인 `system` 구조를 유지하면서, 실무 생산성을 빠르게 끌어올릴 수 있는 오픈소스 패턴을 선별 적용한다.
- 데이터 원본은 계속 `system DB`를 기준으로 유지하고, 외부 레포는 "참고 패턴 + 부분 도입" 원칙으로 사용한다.

## 우선 적용 후보

1. `twentyhq/twenty`
- 용도: CRM 파이프라인/고객 타임라인 UX 패턴
- 도입 포인트: 문의 -> 상담 -> 견적 -> 수임 단계 전환 히스토리 카드, 담당 액션 로그
- 적용 시기: 즉시 착수

2. `refinedev/refine`
- 용도: 관리자 CRUD/필터/테이블 패턴
- 도입 포인트: 문의 목록 고급 필터, 대량 상태 변경, 빠른 편집 모달
- 적용 시기: 즉시 착수

3. `makeplane/plane`
- 용도: 보드형 업무 운영 패턴
- 도입 포인트: 사건 진행 보드, 상태별 WIP 제한, 담당자 큐 가시화
- 적용 시기: 중기

4. `n8n-io/n8n`
- 용도: 알림/백업/동기화 자동화
- 도입 포인트: 접수 발생 알림, 일일 백업, 노션 동기화 재시도 워크플로
- 적용 시기: 선택 도입 (보안/버전 관리 정책 포함)

## 다음 스프린트 권장 작업

1. 문의 목록에 "대량 작업(상태/담당자 일괄 변경)" 추가
2. 사건 상세에 "단계 히스토리 타임라인" 강화
3. 운영 대시보드에 "병목 원인 Top 3" 자동 계산 추가
4. 자동화 도입 시 운영 정책 문서화
- 워크플로별 실패 재시도 횟수
- 장애 알림 채널
- 백업 검증 주기
