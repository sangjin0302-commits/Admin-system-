# Public Website Design References

Admin-system 공개 웹사이트 디자인은 단일 레퍼런스를 그대로 복제하지 않고, 여러 레퍼런스의 장점을 조합한다.

최종 방향:

`태강식 고급감 + 늘함식 차분한 신뢰감 + KB식 전문 분야 구조 + 통식 진행 절차 + Admin-system 고유의 접수번호/처리 내역 조회`

## 1. 태강 스타일

역할:

- 고급스럽고 전문적인 첫인상
- 전문 분야와 상담 CTA 배치
- 사건/사례형 콘텐츠 구조 참고

반영할 점:

- 신뢰감 있는 hero
- 전문 분야별 섹션
- 상담 CTA
- 사례/절차 설명형 콘텐츠 구조

주의할 점:

- 로펌식 성과 중심 문구는 행정사 사이트에 맞게 낮춘다.
- 승소, 결과 보장, 확실한 해결, 즉시 수임 같은 표현은 사용하지 않는다.

## 2. 법무법인 KB 스타일

역할:

- 전문 분야 카드 구조
- FAQ/상담 CTA/위치 정보 구성 참고

반영할 점:

- 전문 분야를 카드형으로 구분
- 왜 이 사무소인가를 설명하는 신뢰 섹션
- FAQ
- 위치/연락처 하단 정보

Admin-system 적용 예:

- 비자/체류
- 인허가
- 법인/단체
- 사실확인/진술서
- 내용증명/민원
- 아포스티유/번역공증

## 3. 법무법인 프런티어 스타일

역할:

- 상담 신청 전환 구조 참고

반영할 점:

- 상담 신청 CTA를 자연스럽게 배치
- 상담 신청/상담 현황 느낌의 전환형 구조
- 전문 분야별 빠른 분류

주의할 점:

- 24시간 법률 상담 같은 표현은 그대로 사용하지 않는다.
- 행정사 톤에 맞게 상담 신청, 접수 후 확인 가능한 정보, 처리 내역 조회로 낮춘다.

## 4. 공동법률사무소 늘함 스타일

역할:

- 차분하고 신뢰감 있는 전문가형 톤 참고

반영할 점:

- 과하지 않은 hero copy
- 주요 업무 분야 카드
- 신뢰 중심 문구
- 부드러운 색감과 여백

Admin-system 카피 방향:

- 복잡한 행정 절차를 차분하게 정리합니다.
- 접수부터 자료 준비, 제출 후 확인까지 한 흐름으로 관리합니다.

## 5. 법무법인 통 스타일

역할:

- 업무 진행 프로세스 설명 참고

반영할 점:

- 단계형 진행 절차
- 고객이 이해하기 쉬운 절차 안내

Admin-system 적용 예:

1. 상담 신청
2. 기본 사실 확인
3. 필요자료 안내
4. 서류 작성/검토
5. 제출/보완 대응
6. 처리 내역 확인

## 6. 로픽셀 / 스타트로이어 참고 자료

역할:

- 법률/전문직 홈페이지 제작 관점의 구조 참고

반영할 점:

- CTA 중심 설계
- 전문성 콘텐츠 배치
- 검색 유입용 콘텐츠 구조
- 홈페이지와 블로그/FAQ 연계

## 7. Admin-system만의 차별점

다른 로펌/전문가 홈페이지와 달리 Admin-system 공개 웹사이트는 아래 기능을 전면에 둘 수 있다.

- 접수번호 발급
- 처리 내역 조회
- 필요자료 안내
- 사건 진행 상태 확인
- 관리자 내부 사건관리와 연결된 고객 경험

핵심 차별 카피:

`접수 후 처리 내역을 직접 확인할 수 있습니다.`

## 8. 권장 공개 웹사이트 레이아웃

상단:

- 로고
- 홈
- 소개
- 전문 분야
- 질의 응답
- 우측 CTA: 상담 신청 / 처리 내역 조회

Hero:

- 로고 기반 3D 입구 또는 신뢰감 있는 상징 이미지
- 문구: 복잡한 행정 절차, 접수부터 처리까지 차분하게 관리합니다.
- CTA: 상담 신청 / 처리 내역 조회

전문 분야:

- 비자/체류
- 인허가
- 법인/단체
- 사실확인/진술서
- 내용증명/민원
- 아포스티유/번역공증

진행 절차:

- 상담 신청
- 사실 확인
- 자료 요청
- 서류 작성
- 제출/보완
- 처리 내역 확인

고객 기능:

- 상담 신청
- 접수번호 발급
- 처리 내역 조회

FAQ:

- 처리기간
- 준비자료
- 비용 안내 방식
- 업무범위
- 자료 제출 방법

하단:

- 사무소 정보
- SNS
- 개인정보처리방침
- 안전 안내문

## 9. 구현 원칙

- 태강을 메인 감성 레퍼런스로 삼되 그대로 복제하지 않는다.
- 최종 방향은 전문가 홈페이지 + 고객 포털형 진행조회다.
- public/admin separation을 유지한다.
- `/intake`는 상담 신청 flow로 연결한다.
- `/track`은 처리 내역 조회 CTA로 연결한다.
- 공개 사이트에는 admin link를 노출하지 않는다.
- 결과 보장/승소/즉시 해결 같은 법률 광고 리스크 문구를 피한다.
- 기능 안정화 이후 visual polish와 3D entrance를 단계적으로 반영한다.
